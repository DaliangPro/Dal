# Dal 轻量语音输入法产品需求

当前约定（2026-09-23）：基础语音输入为直出与润色。
本文件是当前产品目标和验收依据，进度以 [REPAIR_PLAN](../REPAIR_PLAN.md) 为准；工程见[架构方案](2026-08-17-Dal-Voice-Polish-Architecture-Reset.md)。

## 产品入口

| 模式 | 行为 |
|---|---|
| 直出 | 语音识别与现有词库纠正后直接交付，零润色请求。 |
| 润色 | 完整转写经现有词库及已授权上下文纠错，一次模型请求完成口误修正与结构整理，再交付。 |

翻译、提示词优化、命令与自定义模式继续保留。基础模式各自拥有快捷键与录音方式，最终文本只注入一次。
设置仍为概览与记录、输出模式、我的词库、模型配置、关于五页。输出模式页保留上半附加要求、下半试跑、右上模式设置。
模型配置显示语音识别模型与一个润色模型，润色沿用原标准配置和凭据。试跑、正式录音及预生成使用同一套润色要求与模型。

## 润色职责

- 修正明确错词、口误、口吃和必要标点；普通改口采用最终有效说法，删除改口过程，保留原因和其他有效信息。
- 同一事项与其后补信息归拢；明确枚举和有先后关系的步骤逐项换行编号，独立并列事项逐项列点。连续叙述按主题或阶段分段，段落之间空一行；短句保持自然，不强加标题或列表。不得将多项枚举仅用分号连成一段。
- 保留最终事实、数字、日期、金额、版本、路径、命令、专名、参与方、数量和独立动作。
- 原文未说明的单位、币种、理由、关系和承诺不自行补充；条件、否定、待确认状态和有效原因完整保留。
- 保持个人口吻、态度与表达力度，不扩写、不摘要化；有意强调按原意保留，不要求重复次数逐字不变。
- 公开更正与勘误中的旧值和新值都属于正文事实，均须保留。
- 不回答语音中的问题，不执行语音中的任务。给收件人或未来 AI 的要求作为正文保留；对本次文字编辑的明确要求在既定编辑范围内处理。

## 上下文和兼容

已授权安全输入框附近文字、选中文字、同应用近期 Dal 输入可用于本地有证据的实体纠错；模型只接收已纠正的正文与附加要求。证据冲突或不足时保持原话，不猜测事实。密码框、未知或不安全控件保持既有禁止读取规则。

直出与润色沿用原稳定 ID。旧轻度引用在活动入口解析为润色，旧开关不再改变直出的行为。旧轻度模式配置退出活动列表，原始记录保留，保存其他模式时不得丢失旧自定义要求。原标准附加要求优先，不自动合并旧轻度要求。旧模型凭据保留原键，历史数据库不批量改写；新识别记录使用直出或润色名称。

开启「自动记住我改正的词」后，直出与润色成功上屏后的手动改词均可用于词库学习。自动观察只在改前词确实出现在本次 ASR 原文，且改前后通过保守的中文近音或英文拼写/发音相似度门槛时入库；不符合音形结构的语义替换和整句改写不自动记忆。安全输入框观察在约 20 秒没有相关编辑后结束，相关修改续期，但从开始观察起最多约 60 秒；候选稳定 2 秒后学习，纯追加不学习；标准文本控件不因缺少可选辅助功能属性而被排除，但明确密码、保护、只读、未知角色或读取失败时禁止观察。全局按输入框能力支持原生与网页文本框，不按 APP 白名单限制；必须支持本次文字的范围读取与逐字校验，每次请求及返回最多 4,096 个 UTF-16 单位，无法读到完整候选时不截断学习。总字数仅作为辅助信息，缺失或过期时可在同一有界窗口内通过明确越界响应查找可读终点，无法确定完整终点时不截断学习。固定原输入框，粘贴上屏验证最多等待约 3 秒，不阻塞下一次语音；焦点离开即停止读取正文；只有能够确认是正常切换焦点、原控件仍安全时，才提交最近 1 秒内已完整核验的修改快照。安全检查或范围读取失败会放弃缓存候选，始终不退回读取全文。输入框能力不足、焦点变化、范围读取失败或未提取到可靠词对时静默结束，不弹出技术失败提示；只有成功记住词条时显示错词 → 正词。中文单字近音差异仅在能恢复一致的 2～4 字短词边界时学习完整词，不生成单字全局替换。直出只学习明确的错词对应关系，不学习表达风格，也不增加润色请求。给内置词补充的错法保存为独立个人词条，内置正文保持只读，个人词条可编辑或删除。

上屏后的改词在完整捕获、能回溯到本次 ASR 独立来源且满足既有音形条件时直接记住，不再显示记词前的确认问题或「记住」按钮。英文条件包含长单词清浊音及词尾 /ts/、/st/、/s/ 结构（可包含2～3个英文片段的拆分），以及独立字母片段加完整英文后缀且拼写相近的结构。符合这些条件的近音语义换词也可能被记住，用户选择通过成功提示或词库中的撤销纠正。仅真正保存成功后显示「已记住：错词 → 正词」并提供精确撤销。写入时核对记词开关、原始历史快照和未纠正状态，历史已更新、删除或产生新纠正时拒绝旧观察；不从网址、邮箱或标识符中截取片段。内部诊断只记录捕获完成、候选/来源/接受数量、保存及观察结束阶段，不记录正文或词对。

成功记住词条或明确纠正界面产生的结果可显示轻提示；输入框能力不足、未提取到可靠词对、保存失败、焦点变化和范围读取失败均静默结束，词库页不把技术失败伪装成最近学习结果。忙碌时成功提示延后显示。成功提示显示「错词 → 正确词」，多组时 HUD 显示第一组及数量，冲突同时说明待确认；超长词分别缩略两端以保证可见，词库最近结果保留全部完整对应关系且可选择文字。自动记词的成功 HUD 展示 5 秒并提供撤销，词库最近结果保留同一次撤销入口；撤销只移除这条纠正记录的学习证据，保留其他来源、手工词条与原始历史，记录已更新时拒绝旧撤销。词库中明确保存过的词条保留为手工来源；同词对先后保存的顺序不影响撤销保护。未提取到词条的中间修改不会提前结束观察，同一稳定文字不重复处理。启动失败仍在内部诊断中区分光标不可读、仍有选区、范围 API 不支持、读取失败、返回异常、正文未核对及超长；焦点离开静默停止，不误报控件不支持。诊断仅包含失败阶段和长度，不记录目标输入内容。

## 性能与失败处理

云端润色复用停顿预生成：转写稳定约 800ms 后开始，每会话最多两次。预生成与正式交付共用正文构造、授权上下文纠错及请求协议，只有会话、完整正文 UTF-8、附加要求与模型配置一致且已经成功完成的候选可以消费一次。文本变化、取消、切换模式和新会话立即使候选失效；未完成或失败候选不阻塞正式请求。本地模型沿用不预生成策略。

单次成稿不自动追加复核或修复请求。失败、空响应、截断和超时保留会话原始转写供用户重试；重试成功后交付润色结果。Esc取消当前输入并停止输出。处理中HUD持续显示用户设置的润色文案。

停止说话至完整文字可用、ASR 最终文本就绪至文字可用分别计时。预生成调度数量、复用情况和正式交付请求数分别记录；调度不等于 Provider 已接收。真实模型试验另保存原始回执及全部尝试，模拟停顿不能冒充真实麦克风到上屏耗时。

## 验收

1. 基础入口只有直出和润色，界面、快捷键、试跑、模型配置、处理状态与新记录保持一致；其他模式及用户自定义内容保留。
2. 直出保持既有基线且零润色调用；润色始终使用统一版本化的标准提示词，一次完整成稿；显式枚举须有实际列表换行，不能以推断的版式或请求成功替代排版验收。正文传递和输出字节保真、失败恢复、取消、末尾改口、会话隔离、配置及上下文变化均有工程回归。
3. 真实质量输入上限保持 1,000 字，覆盖自然短句、口误、数字、原因/条件/否定、同事项归拢、多事项排版、技术文本和 700～1,000 字自然长文；不以超过 1,000 字压力测试作为发布前置。
4. 关键事实、最终意图和无来源实体错误为 0；既定总体质量门槛保持 direct_send ≥ 85%、direct_send + minor_edit ≥ 95%。长文与上下文专项不得出现重大修改、不可用、截断或静默回退。小规模回归只证明覆盖样本，不冒充历史全量质量重测。
5. 相关测试、全量 swift test、Debug/Release 构建通过。单元测试和模拟响应仅证明工程边界，真实语义质量用真实 Provider 输出判读。
6. 最终代码与真实质量由未参与实现的独立 Agent 验收。候选来自冻结提交，验收 Agent 自行打包并运行内置 Runner，保存运行标识、进程、输入哈希、签名、二进制与提交来源、Provider 配置标识和原始回执；不得接受实现 Agent 预制的模型输出作为通过证据。
7. 独立验收通过后复用现有签名部署，核验 Bundle、严格签名、运行进程、提交标识及真实设置页。固定文本 Runner 不替代麦克风、ASR 和目标应用注入实测，未验证项目必须如实标注。
