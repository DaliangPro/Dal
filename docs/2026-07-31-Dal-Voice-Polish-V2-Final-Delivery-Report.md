# Dal 语音润色 V2 工程交付报告

日期：2026-07-31

状态：三期工程完成并已部署；真实模型产品验收待执行

## 交付结论

Voice Polish V2 已从通用 Prompt 后处理升级为独立、安全、可审计的语音润色管线，并已覆盖安装到 `/Applications/Dal.app`。本次交付完成全部代码、设置交互、确定性测试、评测工具、Release 打包、签名和本机运行核验。

它主要解决四类问题：

1. 复杂改口、旁注、乱序表达和数量变化过去容易被机械清理或丢事实；现在先提取事实与编辑计划，再渲染，并在失败时安全回退。
2. 旧路径的模型调用和清洗规则分散，难以证明不会超预算或把草稿注入目标应用；现在 Fast、Structured、Deep 均有固定调用上限、事实校验和原文保底。
3. 上下文、专有名词和个人表达缺少明确授权与可控存储；现在上下文分三档授权，个人词典可管理、导出和清空，模糊实体只在高置信时纠正。
4. 产品无法从用户的明确纠正中学习；现在只有用户在 Dal 历史内点击“纠正并学习”并确认后才形成样本，可关闭、导出、限量和全部重置。

## 实际效果

- 简短表达走 Fast，减少不必要处理；一般改口走 Structured；复杂表达走 Deep Analyze → Render，必要时最多一次 Repair。
- 每次会话沿用 45 秒硬截止；Fast 最多 1 次、Structured 最多 2 次、Deep 最多 3 次真实模型请求。
- 模型输出必须通过结构、字符、事实、列表数量和长度校验；Hard Fail 不会注入模型草稿，而是回退到完整 ASR 终稿及已确认的安全实体纠正。
- 默认上下文只发送应用场景元数据。选中文本和附近正文都需要用户主动授权；未知场景、安全输入框和捕获失败均不读取正文。
- 支持 Fast / Balanced / Quality 三档质量，以及元数据 / 选中文本 / 附近正文三档上下文。
- 支持个人词典增删改、ASR 热词/纠正词同步、导出、清空和非破坏性 snippet 复制；清空只移除本功能拥有的同步项。
- 支持显式纠正学习、场景化 StyleProfile、候选词典确认、样本上限、导出与重置。关闭个性化后停止采集和请求读取。
