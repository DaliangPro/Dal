# Dal 2.1.0

本次更新整合语音输入、词库与输出模式设置，并增加可切换的HUD样式。

## 本次更新

- 基础语音输入统一为直出与润色。直出不调用润色模型；润色一次修正口误并整理分段、分项，保留原意与个人表达。翻译、提示词优化、命令和自定义模式继续保留。
- 完善润色的术语纠正、停顿预生成、请求诊断与明确纠正学习，恢复润色阶段的自定义文案。
- 整理输出模式设置，将模式设置与删除按钮移到选择框旁。
- 优化词库切换与列表布局，搜索栏保持紧凑、无阴影，并改进侧栏悬停反馈。
- HUD统一40pt高度，提供苹果原生玻璃与不透明墨色两款样式，保留蓝绿波形；同步文字、渐隐与外壳动画，调整光学留白和快速增字裁切。
- 附可编辑Pen全形态设计稿与导出图。

## 下载与安装

- 下载 `Dal-v2.1.0.dmg`，适用于Apple Silicon（arm64）和macOS 14及以上版本。
- 安装包沿用v2.0.0的GitHub手动分发方式，使用既有Muse Local证书签名，未进行Apple Developer ID公证。
- 安装包不捆绑本地SenseVoice、Qwen3-ASR服务及模型；云端识别需配置相应服务凭据。
- 自动更新仍保持关闭，请通过GitHub Release手动下载更新。
- 覆盖安装后若系统要求读取既有钥匙串凭据，请在系统弹窗完成授权；无法写入其他应用时，在系统设置的辅助功能列表中重新启用Dal。

完整HUD设计见[全形态设计资料](design/README.md)。
