# Dal 2.1.1

本次更新修复润色取消后原转写丢失的问题，改进同音名称纠正与润色排版，并精简内部代码。

## 本次更新

- 润色失败后按Esc取消，原转写不再丢失：记录保存在「概览与记录」，标记为「已取消」，可复制使用；取消后仍不会自动写入输入框。
- 近期输入中写明「正式名称为……」「统一名称为……」的名称，现在也能用来纠正口述中的同音错字。
- 润色更准确地区分说给输入法的整理要求与正文：「帮我整理成……」这类要求照做但不写进正文，给收件人的要求保留；说出数量或先后步骤时逐项换行编号；清理口吃重复与口头过渡语，不丢时间限定词。
- 历史数据库只在缺少字段时补齐，失败会记录日志，已有数据不受影响。
- 移除已无入口的资产提炼功能和旧版润色流程的内部代码，历史数据库中的原有数据保持不变；此前把提炼模型设为本地千问时启动会顺带拉起本地服务，现在不再因此启动。
- 自动记词按输入框能力全局判断，补齐异步上屏后的焦点与范围重试；识别错误才会自动学习，失败不再打扰用户。
- 词库支持错法逐条管理，内置词汇列表改为紧凑横向布局，并移除没有实际触发路径的“待确认”入口。
- HUD 处理中保持当前文案宽度，只有真正进入复制卡片时才展开到宽卡片尺寸。

## 下载与安装

- 下载 `Dal-v2.1.1.dmg`，适用于Apple Silicon（arm64）和macOS 14及以上版本。
- 安装包沿用GitHub手动分发方式，使用既有Muse Local证书签名，未进行Apple Developer ID公证。
- 安装包不捆绑本地SenseVoice、Qwen3-ASR服务及模型；云端识别需配置相应服务凭据。
- 自动更新仍保持关闭，请通过GitHub Release手动下载更新。
- 覆盖安装后若系统要求读取既有钥匙串凭据，请在系统弹窗完成授权；无法写入其他应用时，在系统设置的辅助功能列表中重新启用Dal。
