# Muse 2.1.2

改正识别错词后，Muse 会直接记住，不再要求先点击确认；记错了可以撤销。

## 本次更新

- 自动记词统一为“改正后直接记住”：保存成功显示“错词 → 正确词”，附带撤销入口；在“我的词库”也可以撤销最近一次记词。
- 改善英文近音、拆词和字母碎片的学习，例如识别成多个片段的英文名称。仍需来自本次语音识别，并满足近音或拼写条件；邮箱、路径、变量等片段保留保护。
- 改善中文整词学习和编辑观察：连续修改时延续观察，并对本次保存提供定向撤销。
- 撤销自动记词时，保留其他记录提供的同一词对，以及后来手工新增或编辑的词条，避免误删。
- 补充显式实测入口，并修正该入口的录音状态同步；普通启动不显示实测面板。

## 使用说明

保持“我的词库 → 自动记住我改正的词”开启。语音上屏后，在支持的输入框中改正错词，稍作停留；看到“已记住”就已保存，不需要再确认。不满意时点击“撤销此次记词”。

自动记词仍依赖输入框提供必要的读取能力；不满足条件的修改不会保存。近音语义换词也可能被记住，请按需要撤销。未学习过的新识别错法仍可能需要再次改正。

## 下载与安装

- 下载 `Muse-v2.1.2.dmg`，适用于 Apple Silicon（arm64）和 macOS 14 及以上版本。
- 使用既有 Muse Local 证书签名，未进行 Apple 公证；下载者可能遇到 macOS 安全提示。
- 不捆绑本地 SenseVoice、Qwen3-ASR 服务及模型，云端识别需配置相应服务凭据。
- 自动更新仍保持关闭，请通过 GitHub Release 手动下载更新。
- 覆盖安装后如系统要求读取既有钥匙串凭据，请在系统弹窗中完成授权。
